💡 核心价值：将重要人物的发言转化为可量化的市场信号，帮助投资者在信息差窗口期做出更快的决策。

▲ GitHub 仓库截图

💡 核心价值：将线性的代码阅读体验转变为图谱化探索，快速建立对陌生代码库的全局认知。

  • 智能代码解析 — 支持 Python、TypeScript、Go、Rust 等主流语言
  • 概念提取 — 自动识别类、函数、模块、API端点等关键概念

Translate-Book：并行Subagent翻译整本书

⭐ 198 Stars 📈 指数 88.0 🔧 Python

Translate-Book 是Claude Code技能，能够将整本书（PDF/DOCX/EPUB）翻译成任意语言。它使用并行Subagent架构：将书籍分割成小块，每块由独立AI代理翻译，最后合并。

▲ GitHub 仓库截图

翻译一本300页的书籍，传统方式可能需要数小时。更糟糕的是，AI在长对话中容易出现"遗忘"和"输出退化"问题。Translate-Book 的并行化方案完美解决了这些问题：每个chunk独立处理，互不干扰。

💡 核心价值：并行化大幅压缩翻译时间，chunk隔离避免AI长对话中的遗忘问题。

核心功能：

  • 多格式输入 — 支持PDF、DOCX、EPUB
  • 智能分块 — 约6000字符切分，保持段落完整
  • 并行翻译 — 默认8个Subagent同时工作
  • 断点续传 — 已翻译chunk跳过，可从中断处继续
  • 多格式输出 — HTML、DOCX、EPUB、PDF

    🥇 Trump-Code

    sstklen/trump-code

    ⭐ 198 📊 指数 98.0 🔧 Python
    🎬 Demo: Dashboard 实时展示

    📌 项目简介

    Trump-Code 是一个创新性的金融科技项目，通过 AI 技术解码川普的社交媒体发言，分析其与美股波动的潜在关联。项目提供实时 Dashboard，让投资者直观观察言论与市场反应的时间线对比。

    💡 核心价值

    在信息驱动的金融市场中，重要人物发言可能引发市场剧烈波动。Trump-Code 通过 AI 情感分析和事件提取，帮助快速识别可能影响市场的关键信息。

    🎯 解决的问题

    • 时效性不足 — 传统新闻监控滞后，市场已反应完毕
    • 信息过载 — 大量无关推文难以快速筛选
    • 关联性模糊 — 缺乏量化工具衡量言论与市场的相关性
    • 历史回溯困难 — 难以研究过去的言论-市场模式

    🔧 核心功能

    • 实时推文监控 — 自动抓取 Truth Social 等平台发言
    • AI 情感分析 — NLP 模型分析推文情感倾向
    • 关键词提取 — 自动识别涉及的公司、行业、政策
    • 股市数据联动 — 实时获取相关股票/指数价格变动
    • 可视化 Dashboard — 时间线对比、相关性图表

    ⚙️ 技术栈

    Python FastAPI React OpenAI API yfinance PostgreSQL

    🚀 快速开始

    git clone https://github.com/sstklen/trump-code.git
cd trump-code
pip install -r requirements.txt
cp .env.example .env  # 编辑配置
python -m uvicorn app.main:app --reload

    📌 项目简介

    Understand-Anything 是一个 Claude Code 技能，将任意代码库转换为交互式知识图谱。自动分析代码结构、提取关键概念、识别模块间依赖关系，生成可探索的可视化界面。无论是接手陌生项目还是深入理解大型开源库，都能快速建立全局认知。

    💡 核心价值

    将线性的代码阅读体验转变为图谱化探索：从任意节点开始，沿着关系线索发现相关概念，像查看地图一样理解代码库的"地形"。

    🔧 核心功能

    • 智能代码解析 — 支持 Python、TypeScript、Go、Rust 等
    • 概念提取 — 自动识别类、函数、模块、API 端点
    • 依赖分析 — 绘制 import/继承/调用关系图
    • 知识图谱可视化 — D3.js 力导向图，支持搜索
    • 语义搜索 — 用自然语言描述功能，AI 帮你定位

    ⚙️ 技术栈

    TypeScript React 19 D3.js Tree-sitter Claude API

    🚀 快速开始

npx skills add Lum1104/Understand-Anything -a claude-code -g

    📌 项目简介

    Collaborator 是革命性的 AI Agent 开发环境，将终端、代码编辑器、文件浏览器和笔记功能整合在无限画布（Infinite Canvas）上。同时运行多个 AI Agent，在画布上自由排列终端窗口，将相关代码文件和笔记放在旁边。空间化工作方式让 Agent 协作变得直观高效。

    💡 核心价值

    告别"Tab 地狱"！传统 Agent 开发需要在多个终端窗口、编辑器标签页之间来回切换。Collaborator 让所有相关内容放在一个可视化的二维空间里，一目了然。

    🔧 核心功能

    • 无限画布 — 支持平移、缩放的二维空间
    • 终端 Tile — 双击创建终端，绑定 tmux 持久化
    • 代码 Tile — 拖拽文件，带语法高亮编辑器
    • 多工作区 — 不同项目快速切换
    • 状态持久化 — Tile 位置、大小、内容都会保存

    ⚙️ 技术栈

    Electron 40 React 19 Tailwind CSS xterm.js Monaco Editor

    deusyu/translate-book

    ⭐ 198 📊 指数 88.0 🔧 Python
    📸 GitHub 仓库截图

    📌 项目简介

    Translate-Book 是 Claude Code 技能，将整本书（PDF/DOCX/EPUB）翻译成任意语言。使用并行 Subagent 架构：将书籍分割成小块，每块由独立 AI 代理翻译，最后合并。大幅提升速度，避免上下文溢出和输出截断。

    💡 核心价值

    翻译 300 页书籍，传统方式可能数小时。并行化显著压缩时间，每个 chunk 独立处理，避免 AI 长对话中的"遗忘"和"输出退化"。

    🔧 核心功能

    • 多格式输入 — PDF、DOCX、EPUB
    • 智能分块 — 约 6000 字符切分，保持段落完整
    • 并行翻译 — 默认 8 个 Subagent 同时工作
    • 断点续传 — 已翻译 chunk 跳过，可从中断处继续
    • 多格式输出 — HTML、DOCX、EPUB、PDF

    ⚙️ 技术栈

    Python Calibre Pandoc Claude Subagents

    🚀 快速开始

    npx skills add deusyu/translate-book -a claude-code -g

# 使用
translate /path/to/book.pdf to Chinese

    📌 项目简介

    OpenSquirrel 是原生的 GPU 渲染 AI 编程代理控制面板，使用 Rust + GPUI（Zed 的 UI 框架）构建。同时运行 Claude Code、Codex、Cursor Agent 和 OpenCode，统一管理多个代理会话。支持协调器-工作者模式，让主代理自动派遣子代理处理任务。

    💡 核心价值

    "献给那些容易分心的人" — 如果你总想同时运行多个 Agent，却苦于窗口管理混乱，OpenSquirrel 就是为你设计的。原生 Rust + Metal GPU 渲染，性能极佳。

    🔧 核心功能

    • 多 Agent 网格 — 根据数量自动排列布局
    • 协调器/工作者 — 主 Agent 可自动派遣子代理
    • 远程机器支持 — SSH + tmux 在远程服务器运行
    • MCP 集成 — 配置 Playwright 等 MCP 服务器
    • 会话持久化 — 转录、滚动位置、消息都会保存

    ⚙️ 技术栈

    Rust GPUI Metal GPU tmux SSH

    🚀 快速开始

    cargo build --release
./target/release/opensquirrel
